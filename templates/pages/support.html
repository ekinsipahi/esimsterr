Support

Something not working? Let's fix it.

Most problems are one setting. Check the quick fixes first — if none of them apply, send us a message and we reply by email.

Bars but no internet

Turn Data Roaming ON for the eSIM line, and set it as the line for mobile data. That fixes this nine times out of ten.

No network at all

Toggle airplane mode, then pick the carrier manually in network settings. Restart once — the profile registers on the next boot.

Data ran out

Top up from your dashboard — the data attaches to the same eSIM, so there is nothing to reinstall.

Send us a message

Include the ICCID or order reference and we can look at the actual line rather than guessing.
