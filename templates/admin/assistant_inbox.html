It deliberately does NOT extend admin/base.html: this is a full-height, two-pane working tool, and the admin's header, breadcrumbs and sidebar would only take space away from the thread. Polling is the whole engineering problem here. This page sits open all day, so it is written to make the quiet case free: * every request carries the cursor it last saw, and the server answers "unchanged" without reading a single message when nothing has moved; * the thread asks only for messages newer than the last one on screen; * requests chain with setTimeout instead of repeating on setInterval, so a slow response delays the next poll rather than stacking another on top; * a hidden tab polls not at all, and catches up the moment it comes back; * errors back off to a minute rather than hammering a server that is already having a bad time. The chime is synthesised with WebAudio rather than shipped as an audio file: no static asset to serve, and no missing-file silence. Browsers refuse to play anything before a gesture, so it unlocks on the operator's first click, and it only ever rings for a customer who has newly started waiting -- never for the operator's own replies, and never on first load. {% endcomment %} {% csrf_token %}
