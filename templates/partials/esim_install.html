iPhone

  1. Settings → Cellular (or Mobile Service) → Add eSIM
  2. Use QR Code → scan the code, or tap the button on the left
  3. Label it "{{ esim.plan_title|default:'Travel' }}" and keep your primary line as default for calls
  4. Turn on Data Roaming for this line — that is how it reaches the local network

Android

  1. Settings → Network & internet → SIMs → Add eSIM / Download a SIM
  2. Scan the QR code, then confirm the download
  3. Set mobile data to this eSIM and turn on roaming for it
